CHARACTER SWAP CHECKLIST — read the FIRST time you load a non-Luna LoRA
=======================================================================

Everything in this build was tuned against ONE character (heavily freckled,
two-tone hair). Generalisation is UNPROVEN — no other character LoRA existed
on the tuning pod. These are the settings to re-check, in order of risk,
with their documented defaults and sane ranges.

CHARACTER-SPECIFIC — re-check every new character:
1. Base steps/cfg  (Z base KSampler; default 8 steps / cfg 1.0 — the
   AB_CU owner pick; alternative 30 / 1.5-2.0). The old 30/cfg2 default
   was picked FOR dense freckling and is owner-rejected on close-ups
   (S12 blotch). If a heavily-freckled character reads too smooth at
   8/1.0 on body comps, try 30/1.5 there; keep close-ups at 8/1.0.
   NOTE: negatives are inert at cfg 1.0 (live only at cfg>1).
2. Face-pass denoise  (the Z FaceDetailer; default 0.50 — the owner-picked
   PC value; range 0.35-0.55).
   0.50 repaints half the face crop — tuned to soften a densely textured
   face. A softer-featured character may keep more identity at 0.35-0.40.
3. LoRA strength    (Lora Loader Stack; default 1.00; community range for
   Z-Image character LoRAs 0.7-1.0). NOTE: 0.8 coincided with one black
   render on the tuning pod (unexplained, n=1) — if you use sub-1.0
   strengths and see a black frame, re-queue the render, it clears.
4. Trigger word     (positive prompt): use YOUR LoRA's trigger. Measured on
   the tuning character: the LoRA dominates hair/face even without the
   trigger, but include it anyway.
5. Hands prompt (the hands detailer positive): ships neutral ("young
   woman's hand, smooth soft skin..."). Describe YOUR character's hands;
   never use "detailed fingers/fingernails" stacks (measured overbake).
6. Skin-texture channel (the two Z tiled refine passes, res_multistep):
   texture intensity partly reflects the character. If a new character's
   skin reads gritty, first try the face-pass sampler tile (euler_ancestral
   is the smoothest), then denoise 0.25→0.15 on the first tiled pass.

CHARACTER-GENERAL — do not retune per character:
- Architecture (Z-native chain, pass order, detectors, thresholds)
- Mouth detector threshold 0.5 (stage may be deleted entirely — see
  release notes), eyes pass settings, upscaler models
- cfg mechanics (negatives live on the base at cfg>1; detail passes stay
  cfg 1 — raising them is a known-bad change)
- Sampler pairings per pass (documented in the config spec)

VERIFY A SWAP WORKED: render the same seed/prompt twice (must be
bit-identical), then your three standard comps (full-body / portrait /
close-up). Check: identity consistent across comps, no black frames, hands
pass fired if hands visible (server log "1 hand"), face texture reads
photographed not processed.
